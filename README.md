# Alcolika

Sito catalogo B2B per Alcolika – Premium Spirits & Distillati.

## File
- `index.html`: struttura del sito
- `styles.css`: grafica responsive
- `script.js`: filtro catalogo e accesso B2B dimostrativo

## Nota importante
L'accesso B2B incluso è una dimostrazione grafica eseguita nel browser.
Per proteggere realmente i prezzi serve un sistema di autenticazione lato server
o un servizio esterno come Netlify Identity, Supabase o Auth0.
